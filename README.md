
# Vedit

**A video editor by F13**

Create without limits.

Vedit is an Android video editing application built with React Native and Expo.

## Features

- Import videos from your gallery
- Video preview and playback
- Dark and light themes
- Responsive interface
- Video timeline (under development)
- Local-first editing (planned)
- Video export (planned)

## Technology

- React Native
- Expo SDK 54
- TypeScript
- Expo Video
- Expo Image Picker

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

## Android Builds

Preview APK:

```bash
eas build --platform android --profile preview
```

Production AAB:

```bash
eas build --platform android --profile production
```
